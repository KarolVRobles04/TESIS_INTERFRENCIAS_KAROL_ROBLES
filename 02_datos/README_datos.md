# Datos

Esta carpeta separa los datos del trabajo de grado en dos grupos:

- `datos_crudos/`: mediciones originales obtenidas en campo, sin modificar.
- `datos_procesados/`: datos limpiados, organizados o transformados para analisis.

Por ahora no se han cargado datos crudos en esta carpeta. Los archivos CSV disponibles actualmente corresponden a resultados procesados de calibracion y validacion, por eso se encuentran en `04_resultados/tablas/`.
