# Instructivo de acceso a los anexos del trabajo de grado

Este instructivo explica como acceder a los anexos digitales del trabajo de grado desde el repositorio de GitHub.

## 1. Enlace al repositorio

Los anexos se encuentran disponibles en el siguiente repositorio:

<https://github.com/KarolVRobles04/TESIS_INTERFRENCIAS_KAROL_ROBLES>

## 2. Ruta de los anexos

Una vez dentro del repositorio, ingresar a la carpeta:

`05_anexos/evidencias_medicion/`

Enlace directo:

<https://github.com/KarolVRobles04/TESIS_INTERFRENCIAS_KAROL_ROBLES/tree/main/05_anexos/evidencias_medicion>

## 3. Anexos disponibles

En esta carpeta se encuentran los siguientes archivos:

| Anexo | Archivo | Contenido |
| --- | --- | --- |
| Anexo A | `Anexo_A_Caracterizacion_RF.pdf` | Caracterizacion RF de equipos, cables, antenas o elementos asociados al montaje experimental. |
| Anexo B | `Anexo_B_Metodologia.pdf` | Metodologia empleada para las mediciones, procesamiento y validacion. |
| Anexo C | `Anexo_C_TDT.pdf` | Evidencias y resultados asociados a la banda TDT. |
| Anexo D | `Anexo_D_LTE.pdf` | Evidencias y resultados asociados a la banda LTE. |
| Anexo E | `Anexo_E_FM.pdf` | Evidencias y resultados asociados a la banda FM. |

## 4. Como visualizar un anexo

1. Abrir el enlace directo de la carpeta de anexos.
2. Seleccionar el archivo PDF que se desea consultar.
3. GitHub mostrara una vista previa del documento en el navegador.
4. Si la vista previa no carga, seleccionar la opcion **Download** o **View raw** para descargar el archivo.

## 5. Como descargar todos los anexos

Para descargar el repositorio completo:

1. Ingresar al repositorio principal.
2. Seleccionar el boton verde **Code**.
3. Elegir la opcion **Download ZIP**.
4. Descomprimir el archivo descargado.
5. Abrir la carpeta `05_anexos/evidencias_medicion/`.

## 6. Recomendacion para evaluadores

Se recomienda revisar los anexos en el siguiente orden:

1. `Anexo_B_Metodologia.pdf`
2. `Anexo_A_Caracterizacion_RF.pdf`
3. `Anexo_C_TDT.pdf`
4. `Anexo_D_LTE.pdf`
5. `Anexo_E_FM.pdf`

Este orden permite comprender primero la metodologia general y la caracterizacion del montaje, antes de revisar las evidencias especificas por banda de frecuencia.
