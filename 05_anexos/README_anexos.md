# Anexos

Esta carpeta contiene material complementario asociado al desarrollo del proyecto y a la documentacion del proceso experimental.

## Estructura

- `evidencias_medicion/`: contiene documentos anexos, reportes, evidencias y archivos de soporte relacionados con las mediciones realizadas.

## Contenido

Los anexos incluyen informacion adicional utilizada para respaldar la metodologia, la caracterizacion del entorno, el proceso de medicion y el analisis de las bandas FM, LTE y TDT.

## Consideracion

Los archivos almacenados en esta carpeta complementan los resultados y la documentacion principal del proyecto.
